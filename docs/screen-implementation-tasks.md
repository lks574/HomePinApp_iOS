# 화면 구현 태스크

> 최근 추가: `screen-16` 검색·추가 정교화 횡단 — 자연어 규칙 외부화·랭킹·초성·편집거리 fallback·추천 칩·중복 가드·직전 위치 prefill.

화면별 구현 진도(단일 진실 소스)를 `screen-XX` ID로 관리한다.

| ID | 화면 | 상태 | 메모 |
| --- | --- | --- | --- |
| screen-01 | 시안 C 5탭 셸·홈·장소·레시피·추가 시트 | done | UI 우선 1차. 홈은 장보기 요약·장소 바로가기·최근 추가·임박 배너가 실제 이동/편집으로 연결됨. 검색/AI/STT는 후속으로 진행. |
| screen-02 | ItemEditor | in-progress | 물건 추가/편집 공용 에디터. 이름·수량·사진·장소·세부위치·분류·태그·유통기한·메모 지원. 분류/태그는 기존 선택 + 신규 생성 가능. 편집 모드 삭제 지원, 수량 1에서 `-` 탭 시 삭제 확인으로 이어짐. 장소 상세 물건 행 context menu 에 "다 썼어요" 빠른 정리 추가. 잔여: 사진 downsampling/압축 정책. |

| screen-04 | 검색 (중앙 시트) | in-progress | **검색-우선 통합** UX — [추가\|검색] 모드 토글 제거, 단일 입력 필드 하나(타이핑·음성 공용). 입력 즉시 기존 항목 실시간 검색: 물건(이름·위치 경로·장소·세부위치·분류·태그·메모·수량 부분 일치) + 레시피(제목·요약·cuisine/dishType 라벨·태그·재료명/단위/메모 부분 일치)를 물건/레시피 섹션으로 구분 표시. 자연어 문장은 로컬 규칙(`CaptureSearchQuery`)으로 조사·불용어를 제거한 토큰 전체 일치 + 속성 플래그(임박/만료/위치 없음/지금 만들 수 있음/부족 재료)로 보강. 결과 아래 **항상 `+ "{입력어}" 추가하기` 행**을 두고, 이 행을 명시적으로 눌러야만 추가 진행(AI 가 추가/검색 의도 자동추측 안 함 — 오분류 데이터 오염 방지). 추가는 가용 시 AI 파서(`NLParseViewModel`)로 구조화 → screen-09 확인 화면, 미가용·실패·취소 시 단건 스텁 폴백. 파서 추론 중에는 추가 행이 진행 표시로 전환. 음성(`SpeechDictation` 온디바이스 받아쓰기)은 단일 입력 필드를 채우고 `추가하기` 누르면 같은 파서 경로로 합류, 권한·불가용·거부 폴백. 물건 결과 탭 시 `ItemEditor` 편집, 레시피 결과 탭 시 시트 닫고 레시피 탭 상세 push(`AppRouter.openRecipe`, `recipesPath` 바인딩). 중앙 버튼 아이콘은 `sparkles`(AI). 홈/장소의 정적 검색바는 제거해 죽은 입력을 없앴다. 잔여: 기기/모델 게이팅·다운로드 UX, 실기기 추론·한국어 품질 검증. (find/add 의도 자동판별은 본 통합으로 대체·불필요.) **검색 랭킹·초성·편집거리 fallback·빈 입력 추천 칩·중복 추가 가드는 `screen-16`(검색·추가 정교화 횡단)에서 추가.** |
| screen-09 | 확인 드래프트 (AI 추가) | in-progress | AI 파서 결과를 확인/수정/삭제하는 push 화면(`CaptureSheet` 소유). 항목별 이름·수량·장소·세부위치·분류·태그, 신규 vs 기존 매칭 시각 구분(‘신규’ 칩), 다건 배열, 장소 비면 채워야 저장. **분류·태그 인라인 편집**: 값이 비어도 분류·태그 행을 항상 노출, 분류 칩 탭 → 드래프트 전용 시트(`DraftCategoryPickerSheet`)에서 후보 선택·자유입력·없음, 태그 칩별 제거(x)·“+ Tag” 추가 칩 → `DraftTagPickerSheet`. 시트는 insert 없이 `NameMatch`(`AddDraftResolver.match`/`newMatch` 정규화 판정)만 갱신해 신규/기존 칩 시각 규약 자동 유지. 저장 시 `AddDraftResolver` 가 다건 일괄 insert + 신규 위치/분류/태그 생성(없으면생성/있으면매핑, `Item.normalize` 매칭) 후 시트 dismiss. |
