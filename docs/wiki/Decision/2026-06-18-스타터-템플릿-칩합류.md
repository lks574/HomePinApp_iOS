# 2026-06-18 스타터 템플릿 = 정적 데이터 + 칩 staging 합류 (screen-21)

> 빈 앱·새 구역에서 "무엇부터 넣지?" 의 진입 마찰을 줄인다. 구역 종류별로 **자주 두는
> 품목 묶음**을 정적 데이터로 두고, 선택 결과를 [[Capture]] 의 칩 staging 으로 합류시켜
> **명시적 "추가" 에서만** insert 한다. 새 화면·신규 `@Model` 을 만들지 않는다.

## 맥락

- [[2026-06-18-area-생략-캡처-허용-및-멀티-추가]] 에서 칩 staging 코어(`ItemBulkAddModel`
  + `bulkInsert` + CaptureSheet bulk UI + `ItemQuickAddParser`)를 만들었다. 템플릿은
  "텍스트/음성" 대신 "정적 묶음" 을 입력으로 받는 또 하나의 **입력 어댑터**다.
- 시드(`SeedData`/`SeedText`)는 구역(Area) 8종을 en/ko 코드 안에 둔다
  ([[2026-06-16-i18n-다국어화-방침]]). 템플릿 displayName 도 같은 표기를 써서 새 Area
  이름 매칭이 자연스럽게 맞게 한다.

## 결정

### 데이터 위치 = 정적 코드(en/ko 분기), 신규 @Model 없음

- `StarterTemplate { kind, displayName, items: [TemplateItem(name, quantity)] }` 의
  정적 배열로 둔다(`StarterTemplate.swift` + `StarterTemplate+Sets.swift`). 구역 종류는
  시드 Area 8종(주방·냉장고·욕실·거실·안방·드레스룸·현관·창고) + "공통".
- 각 5~7개 품목, **품목명 + 수량 기본값(대부분 1)만** 싣는다. 카테고리/Spot 힌트는
  싣지 않는다(칩 적재 시 위치·분류는 세션 Area/사용자가 정한다).
- en/ko 분기는 `SeedText`/`SeedText+Sets` 패턴 그대로 코드 안에 둔다(.xcstrings 아님,
  런타임 언어 1회 고정). **`#if DEBUG` 게이트는 적용하지 않는다** — 릴리스 노출 기능이다
  (시드 DEBUG 게이트와 다른 점).

### 칩 합류 = 코어 재사용, 자동 저장 없음

- `ItemBulkAddModel.appendChips(from template:)` 로 칩을 적재한다. 템플릿은 위치를
  싣지 않으므로 `parsedArea = nil` → 호출부 세션 Area 로 합류한다(코어 계약 유지:
  이름·수량·area override·중복 배지·`bulkInsert` 불변식 그대로).
- 선택 결과는 **자체 프리뷰가 아니라 칩 staging UI** 로 합류한다. insert 는 사용자가
  "추가" 를 누를 때만(자동 저장 없음).
- 선택 시트 `StarterTemplatePickerSheet`(plain SwiftUI). Area 매칭 `StarterTemplate.match`
  = 새 Area 이름을 `Item.normalize` 후 템플릿 displayName 정규화와 **완전 일치 우선 →
  부분 포함**. 매칭 실패 시 전체 템플릿 목록 picker(빈손 폴백).

### 진입점 2개 (별도 화면 아님 — 진입 트리거)

- (a) **Home 빈 상태 CTA**: `HomeView` 가 물건 0 일 때만 "Start with a template" CTA 를
  노출 → `CaptureSheet(initialMode: .starterTemplate())` 를 템플릿 모드로 연다.
- (b) **새 Area 추가**: `PlaceEditorView.save()` create 분기에서 Area insert 직후
  자체 `@State` 로 "이 구역을 템플릿으로 채울까요?" 후속 `confirmationDialog`(거절 가능).
  수락 시 만든 Area 를 `sessionArea` 로 주입한 채 매칭 템플릿 칩 staging 을 연다.
- bulk 모드 `adapterRow` 에도 "Starter templates" 버튼을 상시 둔다.

## 영향

- 신규: `StarterTemplate`·`StarterTemplate+Sets`·`StarterTemplatePickerSheet`,
  `ItemBulkAddModel.appendChips(from template:)`, `CaptureSheet.InitialMode`,
  HomeView CTA, PlaceEditorView 제안 시트.
- 무변경: `Item` 스키마/모델, `bulkInsert` 불변식, 칩 staging 코어.
- 화면 노트: [[Capture]]. 관련 결정: [[2026-06-18-area-생략-캡처-허용-및-멀티-추가]],
  [[2026-06-16-i18n-다국어화-방침]].
