# 2026-06-12 네비게이션 / UI 구조

시안(`Downloads/음성 플로우.dc.html`, `장소·레시피.dc.html`)으로 확정. UI 우선 개발.

## 1. 탭바 (5-슬롯)

```
홈 │ 장소 │ [✨ 중앙 AI] │ 레시피 │ 설정
```

- 4개 목적지 탭(홈/장소/레시피/설정) + **중앙 AI 추가/검색 버튼(`sparkles`)**. 중앙
  버튼은 탭(목적지)이 아니라 [추가 | 검색] 시트([[Capture]])를 띄운다.
- **(2026-06-16) 중앙 버튼 의미 갱신**: 아이콘을 마이크(`mic.fill`)에서 AI 관용
  `sparkles` 로 바꿨다. 시트 안에서 텍스트·음성(받아쓰기)·AI 파서가 모두 합류하므로
  버튼이 "음성" 단독이 아니라 **AI 추가/검색 진입**을 의미하기 때문이다. 음성 입력은
  시트 내부 공용 마이크 행으로 유지된다(`accessibilityLabel`: "AI add or search").
- 둘째 탭은 "물건" 이 아니라 **장소**(공간별 둘러보기). 물건은 장소 상세에서 본다.
- 검색은 각 화면 상단 검색바(장소 상세 "…에서 찾기", 레시피 "재료 검색").

## 2. 위치 2레벨 UI ↔ 3레벨 모델 매핑 (중요)

시안은 위치를 **2레벨**(`장소 → 수납공간 → 물건`)로 보여준다. 우리 모델은 **3레벨**
([[Space]]⊃[[Area]]⊃[[Spot]]⊃[[Item]]). 매핑:

| UI 용어 | 모델 |
| --- | --- |
| (숨김) | `Space` — 단일 기본 "우리집" 자동 생성, UI 비노출 |
| **장소** | `Area` (주방·안방·냉장고·드레스룸…) |
| **수납공간** | `Spot` (서랍 1번째·옷장 상단·협탁…) |
| 물건 | `Item` |

- v1 은 **단일 Space**. "장소 추가" = 기본 Space 에 `Area` 추가.
- 멀티홈(별장 등)이 필요해지면 후속에 Space 스위처로 노출(모델은 이미 3레벨이라 무리 없음).
- `Item.area`(필수, 앱규칙)는 곧 "장소", `Item.spot`(선택)은 "수납공간".

## 3. 디자인 토큰 (시안 C)

`Shared/DesignSystem` 에 둔다.

- 배경: 페이지 `#E7E4DE`, 화면 `#F4EFE8`
- 강조(테라코타): `#C0603C`, 진한 `#A24E2F`
- 텍스트: 본문 `#2C2722`, 보조 `#6F665C` / `#8A8178` / 흐림 `#A89E92`
- 카드: 흰색, radius 18–20, 옅은 그림자
- 장소 배지: bg `#F3E2D8`, 텍스트 `#A24E2F`
- 재료 칩: 보유 `#F2EDE4`/`#6F665C` · 임박 `#FBEFE8`/`#C0603C` · **부족 점선** `#DCD2C5`(transparent) · 완비 `#E7F2EB`/`#1F8A5B`
- 폰트: Pretendard (번들은 후속, 우선 시스템 폰트)
- 탭바: 반투명 블러 `#F8F4EE`(82%), 중앙 AI 버튼(`sparkles`) = 떠 있는 테라코타 원
- **(2026-06-15) 다크 모드**: 위 값은 라이트 기준. 각 `AppColor` 토큰을
  `Color(lightHex:darkHex:)` 동적 색으로 정의해 라이트/다크를 모두 지원한다(다크는
  웜그레이·테라코타를 어둡게 재해석). 토큰을 쓰는 모든 화면이 자동 적응. 테마 선택은
  [[Settings]] 의 `@AppStorage` → 루트 `preferredColorScheme`.

## 5. (2026-06-15) 탭 간 네비게이션 — AppRouter

초기엔 "typed Route/Router 전역화 미도입, 탭별 `NavigationStack` 으로 충분" 으로
정했다. 그런데 [[Home]] 의 장소 바로가기처럼 **탭 경계를 넘는 이동**(홈 → 장소 탭의
[[PlaceDetail]])이 필요해져, 범위를 아래로 갱신한다.

- **탭 내부 push 는 여전히 각 탭의 `NavigationStack` 이 소유**(장소→상세→물건 등).
- **탭 경계를 넘는 이동만** 얇은 셸 라우터 `AppRouter`(`@Observable`)가 담당한다.
  `RootTabView` 가 소유(`@State`)하고 `.environment` 로 주입. 보유 상태는 최소:
  `selectedTab`, 장소 탭 경로 `placesPath: [Area]`, 레시피 탭 경로 `recipesPath: [Recipe]`.
- 장소/레시피 탭은 `NavigationStack(path:)` 를 각각 `router.placesPath`·
  `router.recipesPath` 에 바인딩한다(탭을 떠나도 경로 유지 → 교차 push 가 탭 재생성
  후에도 살아남음). 바인딩은 `@Bindable` 없이 수동 `Binding` 으로 연결(프로젝트 관례).
- 홈 바로가기: `AppRouter.openPlace(area)` = `placesPath = [area]` + `selectedTab = .places`.
- **(2026-06-16) AI 검색 → 레시피 상세**: [[Capture]] 검색 결과의 레시피를 누르면
  `AppRouter.openRecipe(recipe)` = `recipesPath = [recipe]` + `selectedTab = .recipes`
  로 시트를 닫고 레시피 탭 상세를 push 한다([[PlaceDetail]] 교차 이동과 동형 패턴).

전면 라우터(모든 화면을 typed Route 로 중앙 관리)는 여전히 도입하지 않는다 — 탭
경계 이동에 한정한 최소 셸 라우터다. 다른 탭에서 유사한 교차 이동이 늘면 이 라우터를
확장한다.
