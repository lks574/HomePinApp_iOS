# 2026-06-17 AdMob 광고 수익화 도입 (P1: SDK + 동의/ATT 골격)

> 광고 수익화를 위한 첫 외부 의존성(Google Mobile Ads SDK) 도입, 동의(UMP)·ATT 시작
> 플로우, 플랫폼 분기를 정한다. P1 범위(초기화 골격, 광고 미표시)에 한정한 결정이다.

## 맥락

서버 없이 기기 내부(SwiftData)에 저장하는 로컬 앱에 광고 수익화를 붙인다. 지금까지
`Project.swift` 의 양 타깃은 `dependencies: []` 로 외부 의존성이 전혀 없었다. 광고
SDK 는 (1) 첫 외부 의존성이고, (2) iOS 전용(AdMob 은 네이티브 macOS 미지원)이며, (3)
ATT·UMP 동의처럼 되돌리기 어려운 사용자 추적/프라이버시 결정을 동반한다. 단계는
P1(SDK + 동의/ATT 골격, 광고 미표시) → P2(전면) → P3(보상형)으로 나눴고, 이 결정은
P1 만 다룬다. 계정·실광고 단위가 아직 없어 Google 공식 테스트 ID 만 쓴다.

## 결정

- **광고 포맷 = 전면 + 보상형만.** 배너·네이티브·앱오픈 제외.
- **SDK = Google Mobile Ads SDK(SPM) `13.5.0`(2026-06-09 최신) `.exact` 핀** +
  UMP(User Messaging Platform) `GoogleUserMessagingPlatform` `3.1.0` `.exact` 핀.
  첫 외부 의존성이라 재현성 우선으로 범위가 아닌 정확 버전으로 고정한다. GMA 가 UMP 를
  내부 의존성으로 끌고 오지만 `import UserMessagingPlatform` 직접 사용을 위해 UMP
  패키지도 명시적으로 추가했다(product 직접 링크). min iOS 13 으로 우리 26.5 와 무충돌.
- **플랫폼 = iOS 타깃에만 SDK 링크.** macOS 타깃은 `dependencies: []` 유지(SDK 미지원,
  추가 시 빌드 깨짐). 코드는 `#if canImport(GoogleMobileAds)` + `os(iOS)` 가드로 흡수,
  화면용 공개 인터페이스는 SDK 타입을 노출하지 않아 macOS 에서 no-op 으로 컴파일된다.
- **광고 ID = Google 공식 테스트 앱 ID `ca-app-pub-3940256099942544~1458002511` 만.**
  실광고 ID 하드코딩 금지(출시 직전 교체). `SKAdNetworkItems` 는 Google 권장 50개 식별자.
- **시작 플로우(`AppModel.start(adService:)` → `AdService.startup()`) 순서 = ① UMP
  동의 정보 갱신 + 필요 시 동의 폼 → ② ATT 권한 요청 → ③ `MobileAds.shared.start()`
  SDK 초기화 → `.home` 전환.** 동의·ATT 거부와 무관하게 비개인화 광고로 진행하며 앱
  흐름을 차단하지 않는다. 최소 스플래시 노출과 광고 준비를 병렬로 돌린다.
- **`AdService` = `@MainActor @Observable`**, `AppRootView` 가 소유하고 `.environment`
  로 주입. P1 에서 광고 표시 메서드(`showInterstitialIfEligible(trigger:)`,
  `presentRewarded()`)는 시그니처만 두고 본문은 no-op(P2/P3 에서 구현).
- **프라이버시 = 앱 레벨 `PrivacyInfo.xcprivacy`(iOS 전용 리소스).** 추적 도메인·
  수집 데이터(기기 식별자·제품 상호작용, 모두 추적 목적)·required reason API(UserDefaults
  CA92.1) 선언. AdMob SDK 동봉 매니페스트와 빌드시 병합. 공유 `Resources/**` glob 밖
  (`Resources-iOS/`)에 두어 macOS 번들에 들어가지 않게 했다.

## 대안 / 폐기한 선택지

- **버전 범위(`.upToNextMajor`)** — Google 권장 기본값이지만 첫 외부 의존성이라
  재현성 우선으로 `.exact` 선택. 정기적으로 수동 갱신한다.
- **UMP 를 GMA 의 transitive 의존성으로만 사용** — `import UserMessagingPlatform` 가
  product 미노출로 불안정할 수 있어 UMP 패키지를 명시적으로 추가했다.
- **Mac Catalyst 로 macOS 광고** — 네이티브 macOS 타깃 방침(별도 결정)과 충돌하고
  AdMob 의 Catalyst 지원도 제한적이라 macOS 는 광고 미지원(no-op)으로 둔다.
- **MainActor 콜백 직접 캡처** — UMP `requestConsentInfoUpdate` 의 완료 핸들러가
  nonisolated 로 호출될 수 있어 `@MainActor` 타입(self) 직접 캡처 시 격리 트랩 크래시
  위험. `nonisolated static` 헬퍼 + `withCheckedContinuation` 으로 받아 메인 액터로 hop.

## 영향

- 영향받는 화면: [[Splash]](시작 플로우), 앱 셸([[RootTabView]] 환경 주입)
- 영향받는 모델: 없음(SwiftData `@Model` 변경 없음). `AdService` 는 비영속 셸 서비스.
- 빌드: iOS·macOS 두 타깃 모두 green, 동시성 경고 0, macOS 에 SDK 미링크(회귀 0).
- 후속: P2(전면 광고 로드·빈도·표시), P3(보상형), 출시 전 실광고 ID 교체.
