# 2026-06-17 플랫폼 이미지·UI 추상화 — `PlatformImage` + nav/색 헬퍼

> macOS 네이티브 타깃([[2026-06-17-macOS-네이티브-타깃-추가]]) 추가로 갈라지는
> AppKit/UIKit API 를 `Shared/Platform/` 한 곳에 모아, 호출 측이 `#if os` 를
> 흩뿌리지 않게 한다.

## 맥락

소스 한 벌을 iOS·macOS 두 타깃이 공유하므로(상위 결정), 이미지 타입(`UIImage` vs
`NSImage`)·일부 SwiftUI modifier·동적 색 생성처럼 플랫폼별로 갈리는 지점을 호출부마다
`#if os` 로 분기하면 화면 코드가 지저분해지고 회귀 위험이 커진다. OCR/사진 경로는
이미 `CGImage`+orientation 만 일관되게 뽑아 주면 Vision 이 cross-platform 이라
변환 지점만 모으면 된다.

## 결정

추상화는 `HomePinApp/Sources/Shared/Platform/` 에 모은다.

- **`PlatformImage` typealias** (`PlatformImage.swift`): macOS `NSImage` / iOS
  `UIImage`. 사진 라이브러리·카메라·파일에서 받은 정지 이미지를 OCR 로 넘기거나
  SwiftUI 로 표시하는 경로에서 단일 타입으로 다룬다.
  - `PlatformImage.from(data:)` — 원본 데이터에서 이미지 생성(실패 시 nil).
  - `platformCGImage` — Vision 이 요구하는 `CGImage` 추출. macOS 는
    `cgImage(forProposedRect:context:hints:)`, 그게 없으면 `tiffRepresentation`
    → `CIImage` → `CIContext` 로 굽는 폴백. iOS 는 `cgImage` 우선, 없으면 같은
    `CIImage` 폴백(`CIImage` 백킹 사진 대비).
  - `platformCGImageOrientation` — Vision 회전 메타데이터. iOS 카메라 사진의
    `imageOrientation` 을 `CGImagePropertyOrientation` 으로 옮긴다. macOS `NSImage`
    는 `cgImage(forProposedRect:...)` 가 이미 올바른 방향으로 렌더한 비트맵을
    돌려주므로 **항상 `.up`** 이 기본값이다.
  - `Image(platformImage:)` — SwiftUI `Image` 래퍼(macOS `nsImage:` / iOS
    `uiImage:`), 사용처 분기 제거.
  - 이 도입으로 `TextRecognizer` 에 있던 `CGImage`/orientation 추출 로직이
    `PlatformImage` 로 옮겨가 OCR 인식기는 cross-platform 입력만 받는다.
- **동적 색 provider 분기** (`DesignSystem/Color+Hex.swift`): 라이트/다크 동적 색을
  macOS 는 `NSColor(name:dynamicProvider:)`, iOS 는 `UIColor(dynamicProvider:)`
  로 만들고 `Color(nsColor:)`/`Color(uiColor:)` 로 감싼다. `NSColor`/`UIColor`
  의 `init(hex:)` 도 각 플랫폼 extension 으로 분기. 사용처(디자인 토큰)는 분기 없이
  같은 API 를 호출한다.
- **nav/입력 modifier 헬퍼** (`View+PlatformNav.swift`): iOS 전용 SwiftUI modifier 가
  macOS 에서 컴파일되지 않으므로 `View` extension 으로 한 번만 분기하고 macOS 는
  no-op(타이틀·도구는 윈도우/툴바가 처리)으로 둔다.
  - `compactNavTitle()` — iOS `navigationBarTitleDisplayMode(.inline)`.
  - `hideNavBar()` — iOS `toolbar(.hidden, for: .navigationBar)`.
  - `plainTextInput()` — iOS `textInputAutocapitalization(.never)`.
  - `numericKeyboard(decimal:)` — iOS `keyboardType(.decimalPad/.numberPad)`.
  - `cameraCaptureCover(isPresented:onCapture:)` (`Shared/OCR/CameraImagePicker.swift`)
    — iOS `fullScreenCover` 로 카메라 picker, macOS no-op(호출부가 카메라 버튼을
    `cameraAvailable` 로 숨겨 트리거되지 않음).

## 대안 / 폐기한 선택지

- **호출부마다 `#if os` 분기** — 화면 코드가 지저분해지고 같은 분기가 흩어져 회귀
  위험. 추상화 한 곳으로 모았다.
- **macOS orientation 을 `imageOrientation` 흉내로 추적** — `NSImage` 는
  `imageOrientation` 개념이 없고 `cgImage(forProposedRect:...)` 가 이미 정방향
  비트맵을 주므로 `.up` 고정이 단순·정확.
